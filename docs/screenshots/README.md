# Screenshots

Place high-resolution screenshots of Project RETR0 installer here. These are used for the README and app store listings (IzzyOnDroid/F-Droid).

## Recommended Screenshots

1. **Main Screen:** Showing detection of RR3 and Shizuku status.
2. **Asset Selection:** The list of available mods or assets to install.
3. **Installation Progress:** The UI during an active installation.
4. **Shizuku Authorization:** The prompt or status showing Shizuku is authorized.
5. **Backup/Revert:** The interface for managing game data backups.
6. **Community Hub:** Browsing skins, saves, or music.
7. **Music Import:** The local audio import and metadata editing screen.
8. **Settings/About:** Version information and links.

## Requirements

- **Format:** PNG or JPEG.
- **Ratio:** 16:9 portrait (standard smartphone screen).
- **Quality:** High resolution, no notification icons or status bar clutter if possible.
- **Privacy:** Ensure no personal data is visible in screenshots.
